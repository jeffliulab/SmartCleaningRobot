V1的算法思路是传统的流水线：
感知(LiDAR) → SLAM建图 → 得到全局地图 → 路径规划算法 → 生成路径 → 跟踪执行
每一步都是人手写的算法，逻辑清晰但灵活性差。你需要一个完整的地图才能规划路径。

V2的思路则是端到端的强化学习：
观测(位姿 + LiDAR + 局部覆盖地图) → 神经网络 → 直接输出（线速度, 角速度）
不需要建图、没有路径规划；机器人看到当前的局部信息，神经网络直接告诉他往哪里走。

V2的神经网络架构：MLP
输入 (1066)
1066维向量
pose：3维，x，y，yaw
速度vel：2维，前进线速度，旋转角速度
LiDAR：36维
局部覆盖地图：32x32=1024，0=没扫过，1=扫过了
全局覆盖率：1维，整个房间已经扫过的比例，0-1
合计：1066维

  ▼
输出 (2)
线速度、角速度共2维

观测空间是结构化的向量输入（位姿、速度、LiDAR、覆盖地图展平），不是原始图像，MLP 足以建模这种输入的映射关系。32×32 的覆盖地图虽然有空间结构，但它是二值网格、分辨率低，展平后 MLP 能学会。如果未来接入高分辨率的摄像头图像做视觉导航，会考虑用 CNN 做视觉编码器再接 MLP 策略头。
