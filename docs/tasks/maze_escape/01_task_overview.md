# 01 — 任务概述

## 什么是迷宫逃脱任务

迷宫逃脱（Maze Escape）是一个独立的强化学习任务：将 JetBot 差速驱动机器人放置在程序生成的 DFS 迷宫中的随机位置，目标是在 **120 秒内** 到达迷宫出口。

这个任务独立于扫地机器人清洁任务，作为 RL 算法的练手项目。

## 迷宫生成算法

迷宫使用 **深度优先搜索 (DFS)** 算法生成，产生一个简单连通迷宫（任意两点之间恰好有一条路径）。

### 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 网格大小 | 8 × 8 | 64 个逻辑单元格 |
| 单元格尺寸 | 0.45 m | 通道和墙壁的宽度 |
| 墙壁高度 | 0.3 m | 足够阻挡 LiDAR |
| 随机种子 | 42 | 训练和部署使用相同迷宫 |
| 起始单元格 | (4, 4) | 迷宫中心 |
| 出口位置 | (0.0, -3.15) | 南侧中心墙壁 |

### DFS 生成过程

1. 从中心单元格 (4, 4) 开始
2. 将当前单元格标记为已访问，压入栈
3. 随机选择一个未访问的相邻单元格
4. 打通两个单元格之间的墙壁
5. 移动到新单元格，重复步骤 2-4
6. 如果没有未访问的邻居，退栈回溯
7. 直到所有 64 个单元格都被访问

生成后打开南侧中心墙壁作为出口。

### 坐标系

迷宫中心 (4, 4) 对应世界原点 (0, 0)：

```
世界坐标 Y
    ↑  (北)
    |
    |  [ 迷宫 8×8 ]
    |  中心 = (0, 0)
    |
    +----------→ 世界坐标 X (东)
    |
    出口 (0, -3.15)
```

逻辑单元格 (r, c) 到世界坐标的转换：
- `x = (2*c - 8) * 0.45`
- `y = (8 - 2*r) * 0.45`

## 与清洁任务的区别

| 方面 | 清洁任务 | 迷宫逃脱 |
|------|----------|----------|
| 目标 | 最大化地面覆盖率 | 尽快到达出口 |
| 观测维度 | 1066 维 | 41 维 |
| 观测内容 | 含局部覆盖地图 | 不含覆盖地图 |
| 坐标系 | 世界坐标 | **机体坐标系** |
| 算法 | PPO | **SAC** |
| 奖励 | 覆盖面积 + 里程碑 | BFS 距离缩减 + 到达奖励 |
| 终止条件 | 覆盖率 ≥ 95% 或超时 | 到达出口或超时 (120s) |
| 场景 | 可选（office/hospital 等） | 固定 DFS 迷宫 |

## 环境配置参数

关键配置定义在 `mazenav_env_cfg.py` 中：

```python
@configclass
class MazeEscapeEnvCfg(DirectRLEnvCfg):
    decimation = 2              # 每 2 个仿真步执行 1 次控制
    episode_length_s = 120.0    # 最长 120 秒
    observation_space = 41      # 41 维观测（机体坐标系）
    action_space = 2            # (线速度, 角速度)
    max_linear_vel = 0.3        # 最大 0.3 m/s
    max_angular_vel = 2.0       # 最大 2.0 rad/s
    exit_threshold = 0.3        # 距出口 < 0.3m 视为到达
    randomize_spawn = True      # 随机出生点
```
