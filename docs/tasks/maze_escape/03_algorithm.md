# 03 — SAC 算法详解

## 为什么选择 SAC

| 算法 | 类型 | 探索能力 | 样本效率 | 适合迷宫 | 原因 |
|------|------|---------|---------|---------|------|
| **A*** | 图搜索 | — | — | 需要全局地图 | 无地图时不可用 |
| **左手法则** | 反应式 | — | — | 仅简单连通迷宫 | 动作僵硬，不可学习 |
| **PPO** | On-policy | 中等 | 低 | 一般 | 经验用完即弃，稀疏奖励学习慢 |
| **SAC** | Off-policy | **强** | **高** | **最佳** | 内置熵最大化 + 经验回放 |

SAC (Soft Actor-Critic) 的三大优势：

1. **内置熵最大化**：目标函数包含最大熵项，天然鼓励探索死胡同和岔路
2. **经验回放 (Replay Buffer)**：成功到达出口的经验可反复利用，样本效率远高于 PPO
3. **自动温度调节**：entropy 的权重 (alpha) 自动调节，训练前期多探索，后期多利用

## 观测空间 (41 维，机体坐标系)

```
┌─────────────────────────────────────────────────┐
│  观测向量 (41 维)                                 │
├────────────┬──────┬───────────────────────────────┤
│ 分量       │ 维度 │ 说明                           │
├────────────┼──────┼───────────────────────────────┤
│ vel        │  2   │ (前向线速度, 角速度) 机体坐标系  │
│ lidar      │ 36   │ 360→36 射线, 归一化到 [0,1]     │
│ exit_dir   │  2   │ (sin θ, cos θ) 出口在机体坐标系 │
│ exit_dist  │  1   │ 到出口距离 / 迷宫对角线         │
└────────────┴──────┴───────────────────────────────┘
```

### 关键设计决策

- **去掉了世界坐标 pose(x, y, yaw)**：策略不需要知道"我在世界哪里"，只需要知道"出口在我的哪个方向"
- **出口方向用 (sin θ, cos θ) 而非角度 θ**：避免 ±π 处的不连续跳变
- **LiDAR 保持世界坐标系下的距离**：LiDAR 本身就是以机器人为中心的，天然是机体坐标系

## 动作空间 (2 维)

| 输出 | 范围 | 物理含义 |
|------|------|---------|
| `action[0]` | [-1, 1] → [-0.3, 0.3] m/s | 前向线速度 |
| `action[1]` | [-1, 1] → [-2.0, 2.0] rad/s | 角速度 |

通过差速驱动模型转为左右轮速度：

```python
v_left  = (v - ω × L/2) / R
v_right = (v + ω × L/2) / R
# L = 轮距 0.118m, R = 轮径 0.0325m
```

## 奖励设计

### BFS 距离场

与旧版使用欧氏距离不同，新版使用 **BFS 最短路径距离** 进行奖励 shaping：

```
旧版（欧氏距离）问题示意：

    ┌───┐        机器人需要走 →→→↓ 绕过墙壁
    │ R │→ 欧氏距离变近（奖励+）但撞墙
    │   │   ┌────────┐
    │   │   │ 墙壁   │
    │   │   └────────┘
    │   │              ↓ 正确路径：先远离（欧氏奖励-）
    └───┘    出口 ★

新版（BFS 距离）：
    每个格子预计算到出口的最短路径步数
    机器人沿正确路径走 → BFS 距离减少 → 始终获得正奖励
```

BFS 距离场在环境初始化时预计算，存储为 GPU tensor，每步只需一次索引查找。

### 奖励函数

| 奖励项 | 权重 | 类型 | 触发条件 |
|--------|------|------|---------|
| BFS 距离缩减 | +5.0 | Dense | 每步 `(prev_bfs - curr_bfs) / max_bfs` |
| 到达出口 | +200.0 | Sparse | 距出口 < 0.3m |
| 碰撞惩罚 | -5.0 | Dense | LiDAR 最小距离 < 0.15m |
| 时间惩罚 | -0.05 | Dense | 每步固定 |
| 探索奖励 | +0.5 | Dense | 覆盖新的网格单元 |
| 前向运动 | +0.1 | Dense | `clamp(v_forward, 0) × 0.1` |

### 奖励设计原理

- **BFS 距离缩减**：核心引导信号，确保正确路径始终有正奖励
- **碰撞惩罚加大到 -5.0**：防止机器人学会"蹭墙走"
- **前向运动奖励**：防止原地转圈（SAC 的高熵探索可能导致）
- **探索奖励**：鼓励访问新区域，帮助发现更多路径

## 网络结构

SAC 使用 5 个独立网络：

```
┌──────────────────────────────────────────┐
│  Policy (Actor)                          │
│  GaussianMixin                           │
│  obs(41) → [256, 128, 64] ELU → act(2)  │
│  输出: 均值 + 对数标准差 → 高斯分布采样    │
└──────────────────────────────────────────┘

┌──────────────────────────────────────────┐
│  Critic 1 & 2 (双 Q 网络)                │
│  DeterministicMixin                      │
│  [obs(41), act(2)] → [256, 128, 64] ELU  │
│  → Q值(1)                                │
└──────────────────────────────────────────┘

┌──────────────────────────────────────────┐
│  Target Critic 1 & 2                     │
│  结构同 Critic，参数软更新 (polyak=0.005) │
└──────────────────────────────────────────┘
```

### 与 PPO 的结构区别

| 方面 | PPO | SAC |
|------|-----|-----|
| 网络数量 | 2 (policy + value) | 5 (policy + 2 critics + 2 targets) |
| Critic 输入 | 只有观测 | 观测 + 动作 (拼接) |
| 数据存储 | Rollout buffer (用完即弃) | Replay buffer (50000 条经验) |
| 模型共享 | 可选 | 必须分离 (`separate: True`) |

## 关键超参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `batch_size` | 4096 | 每次从 replay buffer 采样的样本数 |
| `memory_size` | 50000 | Replay buffer 容量 |
| `discount_factor` | 0.99 | 折扣因子 |
| `polyak` | 0.005 | 目标网络软更新系数 τ |
| `learning_rate` | 3e-4 | Actor 和 Critic 学习率 |
| `learn_entropy` | True | 自动调节熵温度 alpha |
| `initial_entropy_value` | 1.0 | 初始熵权重（训练中自动降低） |
| `random_timesteps` | 1000 | 开始学习前随机探索的步数 |
| `learning_starts` | 1000 | 开始梯度更新的最小 buffer 大小 |
| `timesteps` | 3000000 | 总训练步数 |
