## 1. 任务描述

### 1.1 目标

训练 TurtleBot4 机器人在房间内导航到地面上的小物体，用 5-DOF 机械臂抓取，然后放入机器人后方的篮子中。这是本项目中第一个 **移动操控 (Mobile Manipulation)** 任务——同时需要底盘导航和机械臂控制。

### 1.2 核心挑战

| 挑战 | 说明 |
|------|------|
| 高维动作空间 | 8 维：2 维底盘 + 5 维机械臂 + 1 维夹爪 |
| 多目标协调 | 导航→接近→抓取→放置的流程控制 |
| 精细操控 | 夹爪需要在 4cm 范围内准确抓取 |
| 长时间决策 | 最长 180 秒，多次抓取循环 |

### 1.3 课程学习（Curriculum）

本任务分三个阶段逐步增加难度：

| 阶段 | 内容 | 成功标准 |
|------|------|---------|
| Stage 1 | 从 T4 检查点微调；底盘移动，手臂冻结 | 基本导航能力 |
| Stage 2 | 联合导航+抓取；单个随机物体 | >60% 单物体抓取 |
| Stage 3 | 多物体（5个），完整循环 | 尽可能多地拾取 |

## 2. 背景知识

### 2.1 TurtleBot4 + WidowX 250

```
                    WidowX 250 手臂
                         ╱╲
                        ╱  ╲
                       ╱    ╲  5 个关节
                      ╱      ╲ (旋转腰 + 肩 + 肘 + 前臂旋转 + 腕)
                     ╱        ╲
                    ╱    夹爪   ╲
    ┌──────────────┬────────────┐
    │              │  篮子 (后方) │
    │  TurtleBot4  │  0.18×0.18 │
    │  底盘        │  ×0.12m    │
    │  ○        ○  │            │
    └──────────────┴────────────┘
         左轮    右轮
```

- **底盘:** 差分驱动（与 JetBot 类似）
- **手臂:** 5 个旋转关节（腰/肩/肘/前臂旋转/腕角度）
- **夹爪:** 开/合两个状态
- **篮子:** 位于机器人后方 20cm，高 15cm

### 2.2 机械臂关节限制

| 关节 | 名称 | 范围 (rad) | 运动 |
|------|------|-----------|------|
| J1 | 腰 (Waist) | [-3.14, 3.14] | 左右旋转 |
| J2 | 肩 (Shoulder) | [-1.88, 1.99] | 前后摆动 |
| J3 | 肘 (Elbow) | [-2.15, 1.57] | 弯曲 |
| J4 | 前臂旋转 (Forearm Roll) | [-3.14, 3.14] | 绕轴旋转 |
| J5 | 腕角度 (Wrist Angle) | [-1.75, 2.15] | 上下倾斜 |

### 2.3 物体状态机（ObjectTracker）

每个物体有三个状态：

```
   FREE (0)  ──抓取──►  GRASPED (1)  ──放入篮子──►  PLACED (2)
     ▲                      │
     └─────── 掉落 ─────────┘
```

- **FREE:** 在地面上，可被抓取
- **GRASPED:** 被机械臂持有
- **PLACED:** 已放入篮子（永久状态，不可逆）

**抓取判定条件（同时满足）：**
- 物体状态 = FREE
- 末端执行器（EE）到物体距离 < 0.04m
- 夹爪已关闭（joint_pos < 0.005 rad）

**放置判定条件：**
- 物体状态 = GRASPED
- 物体位置在篮子 AABB 范围内（0.18×0.18×0.12m）

## 3. 环境详解

### 3.1 观测空间（94 维）

| 组件 | 维度 | 范围 | 说明 |
|------|------|------|------|
| velocity | 2 | 连续 | 前进线速度 + Z轴角速度 |
| lidar | 72 | [0,1] | 360→72 射线，/3.5m 归一化 |
| detector | 6 | [-1,1] | 3 个最近物体 × [r_norm, sin_theta] |
| ee_state | 5 | [0,1] | EE 相对位置(3) + 臂伸展归一化(1) + 夹爪状态(1) |
| target_rel_pos | 3 | 连续 | 最近 FREE 物体相对于机器人基座的 XYZ |
| target_dist_norm | 1 | [0,1] | EE 到目标距离归一化 |
| in_grasp_range | 1 | {0,1} | EE 是否在抓取范围（< 0.04m） |
| basket_count_norm | 1 | [0,1] | 已放置数 / 总物体数 |
| holding | 1 | {0,1} | 是否正在持有物体 |
| wrist_height | 1 | [0,1] | 手腕 Z 高度 / 0.5 |

**归一化细节：**
- 臂伸展：`norm(EE_pos - shoulder_pos) / MAX_REACH`，shoulder 在 base 上方 0.15m
- 夹爪状态：`gripper_joint_pos / 0.037` 截断到 [0,1]
- LiDAR：5:1 下采样（360→72），距离/3.5m

### 3.2 动作空间（8 维）

| 索引 | 含义 | 范围 | 缩放 |
|------|------|------|------|
| 0 | 线速度 | [-1,1] | ×0.3 m/s |
| 1 | 角速度 | [-1,1] | ×2.0 rad/s |
| 2-6 | 手臂关节增量 | [-1,1] | ×0.05 rad/step |
| 7 | 夹爪 | [-1,1] | >0.5 关闭，≤0.5 打开 |

**夹爪控制逻辑：**
- action[7] > 0.5 → 关闭（目标位置 = 0.0）
- action[7] ≤ 0.5 → 打开（目标位置 = 0.018）

### 3.3 物体配置

| 物体类型 | 数量 | 大小 | 可抓取 |
|---------|------|------|--------|
| 硬币 (Coin) | 2 | 24mm 直径 | 是 |
| 发卡 (Hairpin) | 1 | 50mm 长 | 是 |
| 橡皮 (Eraser) | 1 | 30×15mm | 是 |
| 数据线 (Cable) | 1 | 80mm 卷 | 是 |

物体通过拒绝采样随机放置（最小间距 0.15m，50 次重试）。

### 3.4 篮子参数

| 参数 | 值 |
|------|-----|
| 相对位置 | (0.0, -0.20, 0.15) — 后方 20cm，高 15cm |
| 内部尺寸 | 0.18 × 0.18 × 0.12 m |

## 4. 奖励函数详解

| 组件 | 权重 | 触发条件 | 设计意图 |
|------|------|---------|---------|
| approach_object | +1.0 | (prev_ee_dist - curr_ee_dist).clamp(min=0) | 引导 EE 接近目标 |
| grasp_success | +10.0 | 物体 FREE + EE<0.04m + 夹爪关闭 | 奖励成功抓取 |
| place_in_basket | +50.0 | 物体 GRASPED + 在篮子内 | 奖励放置到篮子（最高奖励） |
| drop_penalty | -5.0 | 曾 GRASPED，现在 EE>0.10m 且未放入篮子 | 惩罚意外掉落 |
| wall_collision | -3.0 | LiDAR 最小距离 < 0.20m | 惩罚撞墙 |
| time_penalty | -0.02 | 每步 | 鼓励快速完成 |

**奖励量级分析：** 放置(+50) >> 抓取(+10) >> 接近(+1) >> 惩罚(-3~-5)。这形成了清晰的优先级层次。

## 7. 结果分析

### 7.1 预期训练时间线

| 阶段 | 步数 | 行为 |
|------|------|------|
| 0 - 500K | 随机移动，偶尔碰到物体 |
| 500K - 2M | 学会接近物体，尝试抓取 |
| 2M - 4M | 抓取成功率提升，开始学习放置 |
| 4M - 5M | 完整循环：导航→抓取→放置 |

### 7.2 成功标准

- Stage 2 目标：单物体抓取成功率 > 60%
- 终极目标：尽可能多地将 5 个物体放入篮子

### 7.3 回放观察要点

| 行为 | 好的表现 | 需改进 |
|------|---------|--------|
| 导航 | 直奔最近物体 | 在房间中打转 |
| 接近 | 平稳减速到物体旁 | 冲过物体或反复抖动 |
| 抓取 | 手臂精准下降，夹爪闭合 | 夹爪没抓住或位置偏 |
| 放置 | 手臂移到篮子上方后松开 | 物体掉到篮子外面 |
| 循环 | 放完一个立刻找下一个 | 放完后停顿或乱走 |

## 8. 常见问题

### Q1: 机器人只移动底盘，手臂不动

**原因：** Stage 1 的手臂冻结逻辑可能未正确解冻。
**解决：** 检查训练是否进入 Stage 2。

### Q2: 手臂抖动严重

**原因：** max_joint_delta 太大或学习率过高。
**解决：** 减小 max_joint_delta（0.05→0.03）或降低 learning_rate。

### Q3: 总是掉落物体

**原因：** 夹爪关闭力度不够或移动太快。
**解决：** 检查 gripper close threshold，确保 action[7] 阈值正确。

### Q4: 训练 5M 步但仍无法放入篮子

**原因：** 奖励梯度断裂——抓取成功但不知道往哪放。
**解决：** 增加训练步数到 8M，或增大 place_in_basket 奖励权重。
