# Legacy Scripts

These are demonstration and benchmark scripts from earlier project phases.
They are preserved for reference but are **not part of the active training pipeline**.

- `Simple_Jetbot/` — Original JetBot coverage demo using Isaac Sim launcher
- `MazeDFSv1_Jetbot/` — Maze escape demo + benchmark algorithms (A*, wall follower, RL agent)

For active training, use the scripts in `train/scripts/common/` with the registered
Gym environments (e.g. `SmartCleaningRobot-MazeEscape-v0`).
